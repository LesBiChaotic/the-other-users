# The Other Users — ARG Horror Game

> A mobile-first, single-player Alternate Reality Game (ARG) horror experience where the player explores **Palinode**, a living digital infrastructure connecting distinct nonhuman communities across continuous ideological and sensory planes.

---

## 🌟 Overview & Design Thesis

Palinode feels like a single mature network translated through several incompatible bodies. Rather than relying on generic cards, dashboard widgets, or decorative glitch wallpaper, each of the eight communities organizes space according to its members' senses and biology:

- **Witness Wire**: Newsprint observation stream with camera crop marks and inference labels (Human Observation Guild & Routine Keepers).
- **Moltinghouse**: Translucent stacked revision sheets and peeling seam mechanics (Borrowfaces & Handfuls).
- **Belowline**: Subterranean bedrock pressure topology and continuous load paths (Knucklerails & Echo Clerks).
- **Vesper**: Non-swipe intimate compatibility fields and negotiated boundary consent (Apartment Choirs & Domestic Symbionts).
- **Pale Market**: Hanging street ledger with explicit provenance trails and permanence costs (Recordborn & Kindly Thieves).
- **Communion**: Vertical liturgical columns with collective marginal commentary (Expectation Wasps & Convergence Believers).
- **Menagerie Directorate**: Physical facility architectural sections with attached live sensor matrices (Containment Operations).
- **Convergence**: Multi-organ anatomical network resolving into six deterministic canonical endings.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or later)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone <YOUR_GITHUB_REPO_URL>
cd the-other-users

# Install dependencies
npm install
```

### Development
```bash
# Start local Vite development server
npm run dev
```

### Production Build
```bash
# Type-check and build production bundle
npm run build

# Preview production build locally
npm run preview
```

### Running Tests
```bash
# Run all 19 Vitest test suites (126 unit & integration tests)
npm run test
```

## 🧪 Architecture & Quality Assurance

- **Framework**: React 19 + TypeScript + Vite
- **State Management**: Zustand with pure event-driven reducers and snapshot persistence
- **Persistence**: IndexedDB (via Dexie) with multi-version schema migration (`CURRENT_SCHEMA_VERSION = 2`) and last-known-good snapshot recovery
- **Routing**: React Router declarative data routes with in-world non-spoiler denial guards (34 canonical surfaces)
- **Accessibility**: 100% WCAG 2.1 AA compliant, reduced-motion safe, screen-reader optimized, 200% font-scaling resilient, mute-safe transcripts
- **Privacy & Security**: Zero device permissions requested (no camera, mic, location, contacts, or external tracking). 100% offline-resilient local execution.

## 📜 Canonical Endings

The narrative culminates in six fully authored deterministic endings:
1. **`END-CHORUS`** — *The Chorus of Difference* (Plurality preserved through living cross-species contradiction).
2. **`END-ORDINARY`** — *A Perfectly Ordinary Person* (Universal standardization and peaceful erasure of friction).
3. **`END-CLOSED`** — *The Closed Tab* (Directorate containment and permanent network severance).
4. **`END-MANY`** — *The Many Bodies* (Severed infrastructure; localized community survival).
5. **`END-MOD`** — *The Moderator's Exception* (Ilyr freed via procedural correction; reciprocal threshold pact).
6. **`END-NOTFOUND`** — *User Not Found* (Player absorbed into Common Body predictive reference model).
